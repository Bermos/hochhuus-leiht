Hochhuus – Ausleihliste / Lending list

DE (CH)
ZIP doppelklicken, Ordner Hochhuus öffnen, START.html im Browser öffnen. Funktioniert offline. Sprache oben auswählen. Einträge werden im Browser gespeichert: regelmässig eine JSON-Sicherung exportieren. Keine automatische Synchronisierung zwischen Geräten oder mit der Online-Liste. Bei einem Wechsel von einer älteren Ausgabe zuerst dort die Liste sichern, anschliessend in dieser Ausgabe die Sicherung öffnen.

EN (UK)
Double-click the ZIP, open the Hochhuus folder, then open START.html in your browser. Works offline. Select your language at the top. Entries are stored in this browser: export a JSON backup regularly. No automatic synchronisation between devices or with the online list. Before switching from an older edition, export its list and then import that backup into this edition.
